# Система учёта заказов «Быстрая доставка»

Учебное приложение на Python для учёта клиентов и заказов с базой данных SQLite. Работать с данными можно двумя способами: через графический интерфейс (GUI) или через терминал (CLI).

## Возможности

### Клиенты
- Просмотр списка всех клиентов.
- Добавление, редактирование и удаление клиентов.
- Данные клиента: имя, телефон и адрес.
- Клиента нельзя удалить, если за ним закреплены заказы.

### Заказы
- Создание, просмотр, редактирование и удаление заказов.
- Выбор клиента из выпадающего списка в карточке заказа.
- Выбор статуса из выпадающего списка: `новый`, `в доставке`, `выполнен`, `отменён`.
- Для нового заказа по умолчанию устанавливается статус `новый`.
- Фильтрация по статусу применяется сразу после выбора значения, без отдельной кнопки «Фильтр».
- Фильтрация по дате с помощью календаря; фильтры по дате и статусу можно использовать одновременно.
- Отчёты по заказам и выручке.

### Импорт, экспорт и журналирование
- Экспорт и импорт данных в JSON и XML.
- Ведение журнала работы приложения и ошибок.
- SQLite используется для хранения данных.

## Требования

- Python 3.10 или новее.
- Tkinter для графического интерфейса (обычно входит в установку Python для Windows).
- Для тестов — `pytest`.

## Установка и запуск

1. Распакуйте проект в папку.
2. Откройте терминал в этой папке. В Windows можно открыть папку в Проводнике, нажать на адресную строку, ввести `cmd` и нажать Enter.
3. При необходимости установите зависимости:

   ```bash
   python -m pip install -r requirements.txt
   ```

### Графический интерфейс (GUI)

Запуск окна приложения:

```bash
python main_gui.py
```

В GUI можно управлять заказами и клиентами, выбирать клиента и статус при создании или редактировании заказа, фильтровать список заказов по статусу и дате, открывать отчёты, а также выполнять импорт и экспорт.

### Терминал (CLI)

Список доступных команд:

```bash
python main_cli.py --help
```

Подробная справка по конкретной команде:

```bash
python main_cli.py add-customer --help
python main_cli.py add-order --help
python main_cli.py orders --help
```

## Примеры работы через терминал

### Показать клиентов

```bash
python main_cli.py customers
```

### Добавить клиента

```bash
python main_cli.py add-customer --name "Иван Иванов" --phone "+79991234567" --address "Москва, Ленина 10"
```

После добавления программа выведет ID клиента. Используйте этот ID при создании заказа.

### Изменить клиента

```bash
python main_cli.py update-customer --id 1 --name "Иван Иванов" --phone "+79990000000" --address "Москва, Мира 5"
```

Замените `1` на ID нужного клиента.

### Удалить клиента

```bash
python main_cli.py delete-customer --id 1
```

Клиента с заказами удалить нельзя.

### Добавить заказ

```bash
python main_cli.py add-order --customer-id 1 --product "Ноутбук" --quantity 1 --price 55000
```

- `--customer-id` — ID существующего клиента.
- `--product` — название товара.
- `--quantity` — количество товара (по умолчанию `1`).
- `--price` — цена за одну единицу товара.
- `--date` — дата в формате `ГГГГ-ММ-ДД`; если не указана, используется текущая дата.
- `--status` — статус заказа; по умолчанию `новый`.

Пример заказа с датой и статусом:

```bash
python main_cli.py add-order --customer-id 1 --product "Клавиатура" --quantity 1 --price 2500 --date 2026-10-13 --status "в доставке"
```

### Посмотреть заказы

```bash
python main_cli.py orders
```

Фильтр по статусу:

```bash
python main_cli.py orders --status "в доставке"
```

Фильтр по диапазону дат:

```bash
python main_cli.py orders --date-from 2026-10-01 --date-to 2026-10-31
```

Можно использовать оба фильтра одновременно:

```bash
python main_cli.py orders --status "выполнен" --date-from 2026-10-01 --date-to 2026-10-31
```

### Отчёт

Отчёт за текущий месяц:

```bash
python main_cli.py report --period month
```

Другие периоды: `day` (день), `week` (неделя), `month` (месяц). Можно указать опорную дату параметром `--date YYYY-MM-DD`.

### Экспорт и импорт

Экспорт в JSON:

```bash
python main_cli.py export --file backup.json
```

Экспорт в XML:

```bash
python main_cli.py export --file backup.xml
```

Импорт из файла:

```bash
python main_cli.py import --file backup.json
```

**Важно:** импорт заменяет текущие данные в базе. Перед импортом рекомендуется сделать экспорт или копию файла базы данных.

## База данных и файлы

Приложение хранит данные в SQLite. При стандартном запуске база создаётся автоматически в каталоге данных проекта. Не удаляйте файл базы данных, если хотите сохранить клиентов и заказы. Для переноса данных можно скопировать файл базы в соответствующее место новой папки проекта.

Файлы журнала находятся в каталоге `logs`, если он предусмотрен текущей конфигурацией проекта.

## Запуск тестов

Из корневой папки проекта выполните:

```bash
python -m pytest -v
```

## Статусы заказов

- `новый` — заказ создан.
- `в доставке` — заказ передан в доставку.
- `выполнен` — заказ доставлен.
- `отменён` — заказ отменён.

## Основные файлы

- `main_gui.py` — графический интерфейс.
- `main_cli.py` — команды терминала.
- `database.py` — работа с базой SQLite.
- `models.py` — модели и проверка данных.
- `data_export.py` — импорт и экспорт JSON/XML.
- `logger_config.py` — настройка журнала.
- `requirements.txt` — зависимости проекта.
